# Projection Boundary

Everything above the boundary is canonical and language-neutral:

- intent IR,
- Gherkin features,
- JSON Schema contracts,
- semantic capability authority,
- decisions and policies,
- DTO projections,
- execution and iteration models,
- port identities,
- proof requirements.

Everything below the boundary is replaceable:

- TypeScript capability bodies,
- TypeScript type projections,
- composition wiring,
- file and schema adapters,
- CLI and library doorways.

A language implementation may change without changing canonical meaning.
